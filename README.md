# CampusIQ — Intelligent Campus Crowd Prediction & Analytics System

CampusIQ is an individual Statistical Machine Learning project that demonstrates how regression models can estimate occupancy in two campus facilities: a university library and cafeteria.

> **Data notice:** The included dataset is synthetic and generated for academic demonstration. It is not live Bennett University data and must not be presented as actual campus measurements.

## Project objectives

- Generate and inspect structured hourly occupancy observations.
- Preprocess data and create time-based features.
- Explore occupancy patterns by location, hour, weekday, examination period and campus event.
- Train and compare regression algorithms.
- Present predicted occupancy and crowd-level insights through a Streamlit dashboard.

## Dataset

The synthetic CSV contains hourly records for 180 days and two locations (Library and Cafeteria). Its columns include date, day of week, hour, weekend indicator, exam-period indicator, campus-event indicator, location, facility capacity, occupancy count and occupancy percentage.

The target variable for regression is `occupancy_count`.

## Machine-learning methods

The planned comparison includes:

1. Linear Regression
2. Decision Tree Regressor
3. Random Forest Regressor
4. K-Nearest Neighbours Regressor

Models are evaluated using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE) and R-squared (R²). The training script uses a chronological holdout split so later observations are reserved for testing.

## Setup on Windows

Open this repository folder in VS Code and run these commands in the integrated PowerShell terminal:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks environment activation, run this in the same terminal and activate again:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.venv\Scripts\Activate.ps1
```

## Run the project

The included CSV is already available. To regenerate it:

```powershell
python generate_data.py
```

Train and compare the models:

```powershell
python train.py
```

This creates `models/best_model.joblib`, `reports/model_comparison.csv` and `reports/training_summary.json`.

Launch the dashboard after training:

```powershell
streamlit run app.py
```

Run the EDA notebook from the repository root in Jupyter or VS Code. Select the project's `.venv` Python kernel. The notebook expects `data/campus_crowd.csv` and saves `data/campus_crowd_preprocessed.csv`.

## Limitations

Because the data is synthetic, model performance only demonstrates how the workflow behaves on the generated patterns. It does not establish real-world predictive accuracy. Real deployment would require authorized, privacy-preserving occupancy observations and evaluation on future real data.
